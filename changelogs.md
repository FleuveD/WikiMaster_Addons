# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.3] - 2026-09-19

### Added

- Performance Mode: Added options in the settings to reduce resource consumption.
  - Disable Animations: Removes all CSS animations and transitions for immediate rendering.
  - Disable Images: Intercepts and blocks all image/video network requests (saving 100% bandwidth). Replaces them with a lightweight WikiMaster logo and uses native rarity colors to style card backgrounds natively.

## [1.0.0] - 2026-09-16

### Added

- Added micro-transaction blocker, the addon will now block all micro-transactions, including offers and premium ads

- Added volume control, the addon will now let you control the volume of the game, including offers and premium ads

- Added debugging console, this console will show you all the actions that the addon is doing in real time

- Added auto-opener for packs, the addon will now open all the packs automatically

- Added auto-claim for achievements, the addon will now claim all the achievements automatically
