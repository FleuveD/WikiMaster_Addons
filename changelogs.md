## [1.0.1] - 2026-09-16

### Added

- Updating README.md with screenshots and better explanations

- Adding LICENSE file to the project



## [1.0.0] - 2026-09-16

### Added

- Added micro-transaction blocker, the addon will now block all micro-transactions, including offers and premium ads

- Added volume control, the addon will now let you control the volume of the game, including offers and premium ads

- Added debugging console, this console will show you all the actions that the addon is doing in real time

- Added auto-opener for packs, the addon will now open all the packs automatically

- Added auto-claim for achievements, the addon will now claim all the achievements automatically
